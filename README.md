## 🚀 Features

- **Intelligent Decision Engine:** Analyzes `git diff` to automatically choose between a zero-downtime hot-reload or a safe hot-restart.  
- **Zero-Downtime Hot Reloads:** Seamlessly swaps out modified cogs via IPC wrapper without taking the bot offline.  
- **Ultra-Fast Polling:** Uses `git ls-remote` for lightweight, near-zero CPU update detection on constrained servers.  
- **Instant Dependency Boot:** Completely bypasses slow `pip install` processes using a massive pre-compiled package caching system.  
- **Pterodactyl Optimized:** Engineered for low-end servers—completes full repo scans and boots in under 1 second.  
- **Auto-Discovery:** Automatically finds `requirements.txt`, bot entry points, and cog architectures without configuration.  
- **Chunked Downloading:** Natively supports downloading and stitching multi-part `.001` archives from GitHub to bypass upload limits.
